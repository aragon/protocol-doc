# Helpers

Protocol **helpers**: contracts that support the core and plugins without being either.

- [Condition Library](/helpers/condition-library.md) — ready-made [permission conditions](/common/permission-conditions.md) for common gating patterns (selector allow-lists, Safe-owner gating) so a DAO needn't write bespoke ones (source: `condition-library`).

## Where to start

The condition library only makes sense once you understand [permissions and conditions](/common/permission-conditions.md); read that first.

_This area is defined by exclusion (helpers are neither core nor plugin), so it risks becoming a grab-bag. If a third unrelated helper lands, split it into its own area rather than accreting here._
